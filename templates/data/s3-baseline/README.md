# S3 Baseline

Provisions S3 buckets with enterprise security and lifecycle configurations.

## Features

- SSE-S3 or SSE-KMS encryption
- Versioning configuration
- Lifecycle policies (transition, expiration)
- Public access block (all four settings)
- TLS enforcement policy
- Cross-region replication (optional)
- Object lock (optional)
