# API Gateway Baseline

Provisions REST or HTTP API Gateway with enterprise configurations.

## Features

- REST or HTTP API Gateway
- Lambda function integration
- WAF ACL (optional)
- Custom domain with ACM certificate (optional)
- Usage plans and API keys (optional)
- Request/response validation
- Throttling and rate limiting
- API caching (optional)
- CloudWatch Logs and metrics
