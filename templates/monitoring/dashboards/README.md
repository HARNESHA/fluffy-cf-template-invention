# CloudWatch Dashboards

Provisions CloudWatch dashboards and alarms for operational visibility.

## Features

- Operational dashboard (compute, network, storage metrics)
- Security dashboard (CloudTrail, GuardDuty, Config findings)
- Cost dashboard (billing metrics)
- Configurable alarms with SNS notifications
- Composite alarms for complex conditions
