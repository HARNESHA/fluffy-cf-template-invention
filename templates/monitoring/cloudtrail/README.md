# CloudTrail Baseline

Enables AWS CloudTrail with organization trail support and CloudWatch Logs integration.

## Features

- Multi-region trail
- Organization trail (optional)
- Log file validation
- S3 bucket with encryption and lifecycle
- CloudWatch Logs integration
- Global service events
- KMS encryption (optional)
