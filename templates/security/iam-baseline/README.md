# IAM Baseline

Provisions IAM account password policy, baseline roles, and permission boundaries.

## Features

- Account password policy (length, age, complexity)
- Permission boundary policy for developer roles
- Baseline service roles for common AWS services
- Instance profiles for EC2 (optional)
