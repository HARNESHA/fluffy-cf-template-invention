# GuardDuty Baseline

Enables Amazon GuardDuty with S3 protection and optional findings export.

## Features

- GuardDuty detector activation
- S3 log data protection
- Findings export to S3 (optional)
- Integration with Security Hub (optional)
- Publishing to CloudWatch Events
