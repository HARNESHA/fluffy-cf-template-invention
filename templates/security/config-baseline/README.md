# Config Baseline

Enables AWS Config with recording, compliance rules, and remediation.

## Features

- AWS Config recorder and delivery channel
- S3 bucket for configuration snapshots
- Managed Config rules (encryption, logging, tagging, etc.)
- Automated remediation (optional)
- SNS notifications for compliance changes (optional)
