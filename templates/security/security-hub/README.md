Enables AWS Security Hub with configurable security standards.

## Features

- Security Hub enablement
- CIS AWS Foundations Benchmark (optional)
- PCI DSS standard (optional)
- AWS Foundational Security Best Practices (optional)
- Multi-account admin account setup (optional)
